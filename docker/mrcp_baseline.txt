# ===== 关键要点 (自研 ASR 插件对照) =====
# 1. 控制通道 = 独立 TCP 连接 (SIP 协商的 channel id)
# 2. 请求格式: MRCP/2.0 <len> <METHOD> <request-id>
# 3. 事件格式: MRCP/2.0 <len> <EVENT-NAME> <request-id> <state>  (无响应行)
# 4. 响应格式: MRCP/2.0 <len> <request-id> <code> <state>
# 5. RECOGNIZE 对应事件应为 RECOGNITION-COMPLETE, 结果同样 application/nlsml+xml
# 6. START-OF-INPUT 在检测到语音时立即发送 (request-id 关联原请求)
# 7. No-Input-Timeout / Start-Input-Timers 为常用头
